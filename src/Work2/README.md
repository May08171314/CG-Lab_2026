### （2）核心技术说明
#### a. MVP 矩阵
- Model（模型变换矩阵）：通过平移、旋转、缩放等几何变换将局部坐标变换为世界坐标。
- View（视点变换矩阵）：通过平移、旋转等几何变换将世界坐标变换为眼睛坐标。
- Projection（投影变换矩阵）：将眼睛坐标系中的物体模型投影到成像平面，形成二维图像。
#### b. 3D 旋转数学
- 在立方体旋转的实现中，使用欧拉角实现 X+Y 双轴同时旋转。
### （3）操作说明
#### a. 3D 三角形
- A/D：旋转三角形
- ESC：退出程序
#### b. 3D 线框立方体 & 3D 彩色面立方体
- A/D：左右旋转
- W/S：上下旋转
- ESC：退出程序
## 3. 实现功能
### （1）`triangle.py`
采用计算机图形学标准渲染流程，完成了基础 3D 三角形的交互渲染：
- 完整 MVP 矩阵变换：实现了模型（Model）、视点（View）、投影（Projection）三大矩阵的组合运算，完整遵循图形学渲染。
- 绕Z轴旋转
- 透视投影：通过透视投影矩阵，将 3D 空间中的三角形投影到 2D 屏幕。
- 3D 空间坐标 → 屏幕坐标映射：完成了从齐次坐标、标准化设备坐标（NDC）到屏幕像素坐标的完整映射流程。
### （2）3D 线框立方体 & 3D 彩色面立方体
- 双轴欧拉角旋转（X + Y）：实现 X+Y 双轴联动旋转。
- W/A/S/D 流畅控制：使用`gui.is_pressed()`实现帧级连续触发，完成丝滑旋转效果。
- 透视投影:定义 12 条边数据结构，利用透视投影算法绘制立体线框，可清晰观察立方体的空间拓扑结构。

## 5. 可调参数说明
所有程序均可自由调整参数：
- 三角形顶点位置（形状）
```python
vertices[0] = [2.0, 0.0, -2.0]
vertices[1] = [0.0, 2.0, -2.0]
vertices[2] = [-2.0, 0.0, -2.0]
```
可修改 x, y, z 坐标，使得改变三角形的大小、形状。
- 相机距离（观察距离）
```python
eye_pos = ti.Vector([0.0, 0.0, 5.0])
```
可以修改 z 值，z值越大，物体越小；z值越小，物体越大。
- 透视视角（FOV）
```python
proj = get_projection_matrix(45.0, 1.0, 0.1, 50.0)
```
- 旋转速度（angle）
- 模型大小
- 线条粗细 / 颜色
- 窗口大小
