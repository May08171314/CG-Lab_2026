## 2. 代码逻辑

### 2.1 基础版（bezier_basic.py)核心逻辑
**核心算法**：De Casteljau递归插值<br>
贝塞尔曲线由一组控制点唯一确定，通过参数 t ∈ [0,1] 遍历生成整条曲线。De Casteljau 算法通过**递归线性插值**实现：
1. 对相邻控制点进行线性插值：P'_i = (1-t)P_i + tP_{i+1}，得到 n-1 个新点
2. 对新点重复插值操作，直到仅剩 1 个点，即为参数 t 对应的曲线上的点
3. 遍历 t 从 0 到 1，生成所有采样点，构成完整贝塞尔曲线
**渲染流程**<br>
1. **初始化**：配置 Taichi GPU 后端，定义画布尺寸（800×800）、最大控制点数量、曲线采样数（1000），预分配显存缓冲区
2. **交互监听**：主循环监听鼠标左键（添加控制点）、键盘c键（清空画布）
3. **曲线计算**：当控制点数量≥2 时，CPU 端批量计算 1000 个采样点的坐标
4. **GPU 渲染**：将采样点一次性传输到 GPU，调用draw_curve_kernel并行点亮对应像素
5. **控件绘制**：绘制红色控制点、灰色控制多边形，实时显示曲线变化
6. **窗口刷新**：将像素缓冲区渲染到窗口，完成一帧绘制

### 2.2 选做1：反走样贝塞尔曲线（bezier_antialiasing.py）核心逻辑
**问题背景**<br>
基础光栅化直接将浮点坐标强转为整数，仅点亮单个像素，导致曲线边缘出现硬锯齿（走样），视觉效果差。<br>
**核心改进：3×3 邻域高斯加权反走样**<br>
1. **保留亚像素精度**：不直接取整浮点坐标，保留小数位精度
2. **邻域遍历**：遍历曲线点周围 3×3 像素范围，覆盖所有受影响的像素
3. **距离加权**：计算曲线点到像素中心的欧氏距离，通过高斯函数生成权重（距离越近，权重越高）
4. **颜色混合**：按权重将绿色叠加到邻域像素，实现边缘自然过渡，弱化锯齿
5. **参数优化**：通过调整ALPHA（衰减系数）控制平滑度，NUM_SEGMENTS（采样数）保证线条连续
**渲染流程**<br>
与基础版完全兼容，仅替换draw_curve_kernel为draw_antialiased_curve，其余交互、计算逻辑不变，保证功能一致性。

### 2.3 选做2：贝塞尔/B样条一键切换（Bspline.py）核心逻辑
**问题背景**<br>
贝塞尔曲线存在全局控制缺陷：修改任意一个控制点，整条曲线都会发生变化；且 n 个控制点对应 n-1 次多项式，控制点过多时计算复杂度高、数值不稳定。
**核心改进：三次均匀 B 样条曲线**
1. **局部控制特性**：每 4 个相邻控制点生成一段曲线，修改一个控制点仅影响相邻 2 段曲线，实现局部编辑
2. **矩阵法简化实现**：采用三次均匀 B 样条标准基矩阵，避免复杂递归计算，提升效率
3. **分段拼接**：n 个控制点（n≥4）对应 n-3 段三次 B 样条曲线，平滑拼接成完整曲线
4. **模式切换**：通过键盘b键一键切换「贝塞尔（绿色）/B 样条（紫色）」，直观对比两种曲线的几何差异
**渲染流程**
1. 新增mode变量标记当前曲线模式（0 = 贝塞尔，1=B 样条）
2. 监听键盘b键，切换模式并打印提示
3. CPU 端根据模式调用不同算法生成采样点：贝塞尔用 De Casteljau，B 样条用三次 B 样条公式
4. GPU 渲染时根据模式设置不同颜色，区分两种曲线
5. 其余交互、控件绘制逻辑与基础版完全一致

## 3. 实现功能
### 3.1 基础功能
1. **贝塞尔曲线绘制**：基于 De Casteljau 算法，支持任意数量控制点生成平滑贝塞尔曲线
2. **实时交互**：鼠标左键点击添加控制点，实时渲染曲线变化
3. **画布清空**：键盘c键一键清空所有控制点，重置画布
4. **GPU加速渲染**：采用「CPU 批量计算 + GPU 并行渲染」架构，保证 60FPS 稳定运行，无卡顿
5. **控件可视化**：红色圆点显示控制点，灰色线条显示控制多边形，直观展示曲线与控制点的关系
6. **坐标归一化**：支持 [0,1] 归一化坐标到屏幕像素的正确映射，保证曲线位置准确

### 3.2 选做1：反走样贝塞尔曲线
1. **3×3 邻域反走样**：通过高斯加权混合邻域像素，消除硬锯齿，实现平滑曲线
2. **参数可配置**：支持调整ALPHA（平滑度）、NUM_SEGMENTS（采样数），适配不同需求
3. **完全兼容基础功能**：保留所有交互、控件逻辑，仅优化渲染质量
4. **性能优化**：GPU 并行执行反走样计算，不影响帧率

### 3.3 选做2：贝塞尔/B样条一键切换
1. **三次均匀 B 样条实现**：支持局部控制，解决贝塞尔曲线全局控制缺陷
2. **一键模式切换**：键盘b键快速切换两种曲线，直观对比几何差异
3. **颜色区分**：贝塞尔用绿色，B 样条用紫色，清晰区分两种曲线
4. **兜底逻辑**：控制点不足 4 个时，自动回退到贝塞尔曲线，保证程序鲁棒性
5. **分段平滑拼接**：多控制点场景下，曲线分段平滑过渡，无断点
